# Анализ системы реального времени

Программа предназначена для анализа временных характеристик задач вычислительной системы реального времени.

В программе реализованы:
- загрузка исходных данных из JSON-файла;
- представление задачи с помощью `dataclass`;
- расчёт временного резерва задачи;
- проверка выполнения дедлайна;
- определение типа дедлайна;
- классификация системы по жёсткости;
- поиск критической задачи;
- расчёт требуемого времени реакции системы;
- расчёт коэффициента загрузки процессора;
- определение архитектуры вычислительной системы;
- формирование таблицы результатов;
- вывод итогового заключения.

## Модель задачи

Для хранения параметров используется класс `Task`, реализованный с помощью `@dataclass`.

Каждая задача содержит:

- `name` — название задачи;
- `task_class` — класс задачи;
- `C` — время выполнения;
- `D` — относительный дедлайн;
- `T` — период задачи.

Соответствующая структура используется непосредственно в программе.

## Формат входных данных

Исходные данные программа получает из JSON-файла.

Файл должен содержать две основные части:

```json
{
    "tasks": [
        {
            "name": "Название задачи",
            "class": "жёсткое",
            "C": 2,
            "D": 10,
            "T": 10
        }
    ],
    "system": {
        "n_cpu": 1,
        "has_network": false,
        "name": "Название системы"
    }
}
```

Раздел `tasks` содержит список задач, а раздел `system` — параметры вычислительной системы. Программа считывает название системы, количество процессоров и наличие сетевого соединения.

По умолчанию программа ищет файл:

```text
specifications.json
```

Также имя JSON-файла можно передать программе при запуске через аргумент командной строки.

## Расчёт временного резерва

Для каждой задачи рассчитывается временной резерв:

```text
L = D - C
```

Он реализован функцией:

```python
def slack(task: Task) -> float:
    return task.D - task.C
```

Если `L >= 0`, задача считается выполнимой в изолированных условиях.

## Определение типа дедлайна

Тип дедлайна определяется сравнением `D` и `T`:

- `D = T` — неявный дедлайн;
- `D < T` — ограниченный дедлайн;
- `D > T` — произвольный дедлайн.

Эта логика реализована в функции `deadline_type()`.

## Классификация системы

Система классифицируется по наличию жёстких задач.

Если среди задач присутствует хотя бы одна задача класса `жёсткое`, система определяется как:

```text
жёсткого реального времени
```

В противном случае:

```text
мягкого реального времени
```

Соответствующая проверка выполняется функцией `classify_system()`.

## Критическая задача

Критическая задача определяется среди жёстких задач.

Программа формирует список жёстких задач и выбирает задачу с минимальным значением временного резерва `L`.

Если жёстких задач нет, критическая задача отсутствует.

## Требуемое время реакции

Требуемое время реакции определяется по минимальному дедлайну среди жёстких задач.

Если жёстких задач нет, используется минимальный дедлайн среди всех задач.

Результат выводится в формате:

```text
R_треб = ... мс
```

## Коэффициент загрузки

Для оценки загрузки вычислительной системы используется сумма отношений времени выполнения к периоду каждой задачи:

```text
U = Σ(C / T)
```

В программе расчёт выполняется функцией:

```python
def utilization(tasks: List[Task]) -> float:
    return sum(task.C / task.T for task in tasks)
```

После расчёта программа проверяет условие:

```text
U <= 1
```

Если условие выполняется, загрузка системы считается допустимой.

## Классификация архитектуры

Архитектура определяется по двум параметрам:

- количеству процессоров;
- наличию сетевого соединения.

Используется следующая классификация:

```text
есть сеть       → распределённая
нет сети + 1 CPU → однопроцессорная
нет сети + >1 CPU → многопроцессорная
```

Эта логика реализована функцией `classify_architecture()`.

## Запуск программы

Для запуска программы используется Python:

```bash
python Deadline.py
```

При таком запуске используется файл:

```text
specifications.json
```

Если необходимо указать другой JSON-файл:

```bash
python Deadline.py имя_файла.json
```

Программа автоматически формирует путь к каталогу `data` относительно расположения файла программы. Если указанный файл отсутствует, выводится сообщение об ошибке.
